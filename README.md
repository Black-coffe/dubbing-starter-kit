# dubbing-starter-kit: дубляж ролика RU → UK с Claude Code

Материалы ролика 4 канала «AI под работу»: конвейер, который берёт ролик с русской речью и делает украинскую
дорожку тем же голосом, тремя способами. Дублируется ролик 3: https://youtu.be/FA1oVqBTUeM (фрагмент 3:15).
Все материалы выпуска: https://andrievskii.site/materials

| Вариант | Что внутри | Скрипт | Цена за ролик 20 мин |
|---|---|---|---|
| A | Demucs + faster-whisper, перевод Claude по глоссарию, озвучка ElevenLabs клоном голоса, подгонка по времени | `dub.py` | около $0.20 по замеру на ролике 4 (цена озвучки действовала по акции) |
| B | готовый сервис ElevenLabs Dubbing API, для сравнения | `eldub.py` | от $10 до $23 |
| C | всё локально и бесплатно: перевод в Ollama (MamayLM 12B), голос OmniVoice | `variant_local.py`, `tts_omnivoice.py` | около $0.01, только электричество |

Файлы: `TASK.md` и `DECISIONS.md` (задача и почему выбраны эти компоненты), `glossary.json` (словарь терминов:
что не переводить, как произносить), `ab.html` (страница, где дорожки переключаются каждые несколько секунд).

## Установка
1. Python 3.12 и `ffmpeg` в `PATH`.
2. Зависимости (лучше в отдельном виртуальном окружении): `pip install torch demucs faster-whisper anthropic requests numpy soundfile`.
   На Windows с GPU `faster-whisper` нужны пакеты `nvidia-cublas-cu12` и `nvidia-cudnn-cu12`.
3. Положи своё видео с русской речью в `input/` (например `input/video.mp4`) и образец своего голоса в
   `input/voice-sample.wav` (моно WAV, 1-2 минуты чистой речи, нужен для C).

## Что нужно своё
- `ANTHROPIC_API_KEY` для перевода в A.
- `ELEVENLABS_API_KEY` и `ELEVENLABS_VOICE_ID` (клон твоего голоса в ElevenLabs) для A; `ELEVENLABS_API_KEY` для B.
- Для C нужна видеокарта (GPU, у автора 24 ГБ) и отдельное окружение для OmniVoice. Путь к его Python:
  `OMNI_PY=путь/к/omni-env/Scripts/python.exe`. В Ollama должна быть модель из `variant_local.py` (`LLM`).
- Ключи читаются из переменных окружения по имени, в репозитории их нет.

## Запуск
Все команды из корня репозитория. Промежуточные файлы лежат в `work/<имя видео>/`, итог в `output/`.

A, весь конвейер (продолжается с места остановки):
`python dub.py run input/video.mp4`
Перед озвучкой конвейер останавливается: проверь перевод в `work/<имя>/phrases_uk.txt`, потом запусти ту же команду
ещё раз. Отдельные шаги: `python dub.py <extract|transcribe|translate|synth|mix|mux> input/video.mp4`.
Результат: `output/<имя>_uk.m4a`, дорожка для YouTube Studio (Языки, дубляж).

B, сервис для сравнения:
`python eldub.py input/video.mp4` -> `output/<имя>_eldub.m4a`

C, всё локально:
`python variant_local.py input/video.mp4` -> `output/<имя>_local.m4a`

Дорожки A/B/C готового фрагмента (чтобы послушать, не запуская ничего) лежат в `tracks/`, описание в
`tracks/README.md`. Открой `ab.html`: она ждёт `tracks/A.m4a`, `B.m4a`, `C.m4a` и видео фрагмента в `input/`.

## Лицензии
Код конвейера — по лицензии репозитория. Веса OmniVoice (вариант C) распространяются под CC-BY-NC:
только некоммерческое использование. Для озвучки канала, который зарабатывает, C не подходит.

## Домашка
Продублируй 30 секунд своего ролика на другой язык своим голосом и сравни результат на слух с готовым сервисом.

1. Возьми фрагмент своего видео на 30 секунд и положи в папку вместе с описанием задачи; пусть Claude Code сначала расспросит тебя про сервисы, железо и бюджет.
2. Прогони фрагмент через конвейер, прочитай перевод глазами рядом с оригиналом и исправь то, что глоссарий не ловит.
3. Включи свою дорожку и дорожку готового сервиса, чередуя каждые 6 секунд с того же места, и запиши, какая звучит лучше и сколько стоила.

Если вы такое уже делали — напишите в комментариях, какой язык и какой вариант выбрали, и где у вас сломалось произношение.
