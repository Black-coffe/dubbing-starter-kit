## Отделение голоса от фона: Demucs v4

**Почему:**
- Бесплатно, лицензия MIT, монетизации не мешает.
- Работает на Windows и на CUDA. Нужно около 7 ГБ видеопамяти, на 3090 помещается даже при нынешней загрузке.
- Нужен только для роликов без отдельной дорожки голоса (демо-фрагмент и старые ролики). В новых роликах микрофон пишется отдельно, так что этот шаг нужен редко, и платить за него за минуты нет смысла.
- Обработка идёт на своём компьютере, ролик никуда не загружается.

**Риски:**
- Основной репозиторий в архиве с 01.01.2025 и не обновляется, есть форк. Модели сделаны для музыки: фон получается как сумма «всего, кроме вокала».

**Отклонено:**

| Вариант | Причина |
|---|---|
| LALAL.AI, AudioShake, Music.AI, MVSEP | Платно (~$1.3–2.6 за ролик), нужно загружать ролик в облако. Для редкой задачи локальный вариант проще |
| ElevenLabs Voice Isolator | Отдаёт только голос, дорожки фона не даёт, а для сведения нужен именно фон |
| audio-separator / UVR (модели RoFormer, MDX) | Возможно, качественнее, но у многих весов RoFormer и MDX от сообщества лицензия не указана. UVR — программа с интерфейсом, не для командной строки |
| Spleeter | Старые модели, качество ниже Demucs. В обычном Windows видеокарту, вероятно, не использует |

## Распознавание речи: faster-whisper

**Почему:**
- Бесплатно, лицензия MIT (веса Whisper тоже MIT).
- Уже установлен, и его движок CTranslate2 на машине автора видит видеокарту. Готов к работе без доустановки.
- Русский распознаёт хорошо. Отдаёт таймкоды слов, нужные для нарезки на куски по 10–15 с.
- Английские термины можно подсказать через `initial_prompt` и `hotwords`. Остальное исправит словарь терминов после распознавания.

**Отклонено:**

| Вариант | Причина |
|---|---|
| ElevenLabs Scribe, Deepgram, Speechmatics, Groq и другие облачные сервисы | Дёшевы ($0.01–0.32 за ролик), но нужно загружать аудио. При готовом локальном варианте преимущества не дают |
| OpenAI gpt-transcribe / gpt-4o-transcribe | Нет таймкодов слов |
| AssemblyAI | Для русского практически нельзя подсказать словарь терминов |
| WhisperX | Точнее ставит таймкоды, но требует PyTorch с CUDA и дополнительных моделей. Можно вернуться, если таймкоды faster-whisper окажутся неточными |
| GigaAM | Сделана для русского, но своего словаря нет, так что английские термины — риск. Для длинного аудио нужен дополнительный инструмент нарезки |
| Parakeet / Canary | Официально только Linux, подсказка словаря требует настройки |

## Перевод: Claude Sonnet 5.5

**Почему:**
- Глоссарий, обращение на «ты», контекст всего ролика и учёт длительности кусков задаются промптом. Классический машинный перевод умеет только глоссарий.
- Весь транскрипт 20-минутного ролика помещается в один запрос.
- $0.72 за ролик при трёх проходах. Через Batch вдвое дешевле, а кэширование промпта удешевляет повторные проходы с тем же глоссарием.
- Видеокарта остаётся свободной: локальным LLM на 17–20 ГБ пришлось бы освобождать видеопамять.

**Риски:**
- По документации Anthropic, у новых моделей на тот же текст уходит примерно на 30% больше токенов, чем у старых. Реальная цена может быть немного выше расчётной.

**Отклонено:**

| Вариант | Причина |
|---|---|
| Claude Opus 5.5 | В 2 раза дороже ($1.44). Можно попробовать, если качество Sonnet не устроит |
| Claude Haiku 4.5 | Дешевле ($0.36), но риск хуже справиться с тонкостями перевода и терминами |
| GPT, Gemini, DeepSeek, Mistral | Сопоставимы по возможностям. DeepSeek обрабатывает данные в КНР, Gemini 3.1 Pro пока Preview |
| DeepL, Google Translate, Azure, Amazon | Ни «ты», ни контекста ролика, ни учёта длительности кусков, только глоссарий. Цены DeepL подтверждены только вторичными источниками |
| Локальные LLM (Qwen, Gemma, MamayLM, Lapa) | Большие модели влезают в 24 ГБ только при свободной видеокарте. Качество украинского не проверено |
| NLLB | Лицензия запрещает коммерческое использование |
| MADLAD | Переводит по предложениям, без глоссария и контекста |

## Озвучка: ElevenLabs, клон голоса автора

**Почему:**
- Украинский есть во всех актуальных моделях (v4, v3, Multilingual v2, Flash).
- Эмоциональные теги в v3/v4 помогают с интонацией, а она для автора очень важна.
- Словари произношения позволяют правильно произносить английские термины (Claude Code, MCP).
- Можно передать текст соседних кусков, чтобы интонация не прыгала на стыках.
- Этот вариант автор изначально предпочитал.
- Через API на тарифе Creator ($22/мес) выходит $2.75 за ролик. С переозвучками — $4.00.

**Открытые вопросы:**
- **Быстрый или профессиональный клон.** Быстрый клон доступен со Starter, для него хватает имеющегося образца. Профессиональный доступен с Creator, требует 30–180 мин записи и заметно точнее по сходству. Не решено.
- **API или приложение.** Через API дешевле ($2.75/$4.00), чем через приложение ($3.63/$9.03), потому что в API тариф Creator включает 275k символов, а не 121k.
- **Сравнение с локальной моделью.** В TASK.md записано обязательное слепое сравнение с локальной моделью на 3090. После этого выбора нужно решить, проводить ли его. Кандидаты: dots.tts или Higgs TTS 3.

**Отклонено:**

| Вариант | Причина |
|---|---|
| Локальные модели (dots.tts, Higgs TTS 3, RVC и др.) | Автор сомневается, что они повторят голос так же хорошо. Украинский есть у немногих. dots.tts и Higgs работают на Linux (у автора — через WSL2). Качество интонации на украинском не проверено |
| OmniVoice, Fish S2 Pro (локально), XTTS-v2, F5-TTS | Лицензии запрещают коммерческое использование (у Fish S2 Pro — только по договору) или нет украинского |
| Cartesia, Fish Audio API, MiniMax, Inworld | Украинский есть, некоторые дешевле. Но клон делается на одном языке, а у Inworld качество украинского «зависит от голоса» |
| Azure Personal Voice | Доступ только по одобренной заявке. Качество ниже профессиональных голосов |
| Respeecher | Клон своего голоса, по-видимому, только в корпоративном тарифе. Дороже ($11.13) |
| Google, OpenAI, Hume, Resemble, Speechify, Amazon Polly, WellSaid | Нет украинского или нет клонирования голоса |

## Подгонка по времени и сведение: ffmpeg + Rubber Band

**Почему:**
- Бесплатно. ffmpeg уже установлен, и в его сборке есть все нужные фильтры: `rubberband`, `atempo`, `loudnorm`. Ставить ничего не нужно.
- Rubber Band (движок R3) растягивает речь качественнее, чем `atempo`. Это важно, потому что куски будем ускорять до +10–15%.
- `loudnorm` выравнивает громкость по EBU R128, `amix` смешивает голос с фоном. Всё делается в ffmpeg.
- Лицензия GPL позволяет обрабатывать свои файлы, коммерческая лицензия нужна только для распространения закрытого ПО.

**Отклонено:**

| Вариант | Причина |
|---|---|
| Только `atempo` | Качество речи при заметном растяжении хуже, чем у Rubber Band. Остаётся запасным вариантом |
| SoX | Нет выравнивания громкости по LUFS, проект не развивается |
| pyloudnorm | Не нужен: `loudnorm` в ffmpeg делает то же самое |

## Отклонённая альтернатива: готовый сервис дубляжа

ElevenLabs Dubbing, HeyGen, Rask AI, Azure Video Translation, Dubverse и YouTube Auto-dubbing отклонены целиком в пользу собственной системы. Причины:
- В готовых сервисах мало контроля над остановками для проверки и над решениями по кускам. В ElevenLabs Dubbing v2 править перевод через API можно только на корпоративном тарифе, а Dubbing Studio в режиме поддержки.
- Они дороже: $6–44 за ролик против ~$3.50–4.70.
- YouTube Auto-dubbing не поддерживает перевод с русского на украинский.

## Что нужно подготовить на машине

- Поставить PyTorch с поддержкой CUDA для Demucs: сейчас установлен вариант только для процессора (`2.14.0+cpu`). Лучше в отдельное виртуальное окружение.
- Хранить модели на диске D: — на C: свободно 68 ГБ.
- Перед запуском Demucs освободить часть видеопамяти (сейчас занято 16.4 из 24 ГБ), хотя ~7 ГБ Demucs должны поместиться.
- Получить ключи API: Anthropic и ElevenLabs.
